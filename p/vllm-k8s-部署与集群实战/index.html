vLLM on K8s 架构
├── 存储（Storage）
│   ├── PV - 模型文件持久卷
│   └── PVC - 模型存储声明
├── 工作负载（Workload）
│   └── Deployment - vLLM服务部署
├── 网络（Networking）
│   ├── Service - 内部服务发现
│   └── Ingress - 外部访问入口
├── 配置（Config）
│   ├── ConfigMap - 配置参数
│   └── Secret - 敏感信息
└── 资源（Resources）
    └── GPU - nvidia.com/gpu资源请求

部署方式对比

方式 优点 缺点 适用场景
单Pod 简单直接 无高可用 测试开发
Deployment 支持扩缩容、滚动更新 需要配置 生产环境
StatefulSet 稳定网络标识 复杂 有状态服务

本方案使用 Deployment 方式部署vLLM。

存储配置

为什么需要持久化存储

问题：vLLM Pod重启后，模型文件会丢失吗？

答案：如果模型在容器内，重启会丢失。需要用持久化存储。

解决方案：

  1. 预先下载模型到共享存储
  2. 通过PVC挂载到Pod
  3. Pod重启后模型文件仍然存在

存储方案选择

存储类型 特点 适用场景
Local PV 性能最好，单节点 单节点部署
NFS 共享存储，多节点 多节点部署
Ceph 分布式存储，高可用 大规模生产

# local-pv.yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: models-pv
spec:
  capacity:
    storage: 500Gi
  volumeMode: Filesystem
  accessModes:
  - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: local-storage
  local:
    path: /data/models  # 节点上的模型目录
  nodeAffinity:
    required:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - gpu-node-1  # 替换为你的GPU节点名

# vllm-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: vllm-qwen-7b
  namespace: llm-serving
  labels:
    app: vllm
    model: qwen-7b
spec:
  replicas: 1
  selector:
    matchLabels:
      app: vllm
      model: qwen-7b
  template:
    metadata:
      labels:
        app: vllm
        model: qwen-7b
    spec:
      # 节点选择器（可选）
      nodeSelector:
        nvidia.com/gpu.present: "true"

      # 容器配置
      containers:
      - name: vllm
        image: vllm/vllm-openai:v0.17.1
        args:
        - --model
        - /models/Qwen2-7B-Instruct
        - --host
        - "0.0.0.0"
        - --port
        - "8000"
        - --trust-remote-code
        - --gpu-memory-utilization
        - "0.9"
        - --max-model-len
        - "4096"

        # 资源配置
        resources:
          limits:
            nvidia.com/gpu: 1
            memory: "16Gi"
            cpu: "4"
          requests:
            memory: "8Gi"
            cpu: "2"

        # 存储挂载
        volumeMounts:
        - name: models
          mountPath: /models

        # 端口配置
        ports:
        - containerPort: 8000
          name: http
          protocol: TCP

        # 健康检查
        livenessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 120  # 模型加载需要时间
          periodSeconds: 10
          timeoutSeconds: 5

        readinessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 60
          periodSeconds: 5
          timeoutSeconds: 3

      # 存储卷
      volumes:
      - name: models
        persistentVolumeClaim:
          claimName: models-pvc

Service类型选择

类型 特点 适用场景
ClusterIP 仅集群内访问 内部服务调用
NodePort 通过节点端口暴露 测试环境
LoadBalancer 云厂商负载均衡 云上生产环境
ExternalName DNS别名 外部服务引用

# vllm-full.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: vllm-qwen-7b
  namespace: llm-serving
  labels:
    app: vllm
    model: qwen-7b
spec:
  replicas: 2
  selector:
    matchLabels:
      app: vllm
      model: qwen-7b
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  template:
    metadata:
      labels:
        app: vllm
        model: qwen-7b
    spec:
      nodeSelector:
        nvidia.com/gpu.present: "true"
      affinity:
        podAntiAffinity:
          preferredDuringSchedulingIgnoredDuringExecution:
          - weight: 100
            podAffinityTerm:
              labelSelector:
                matchLabels:
                  app: vllm
              topologyKey: kubernetes.io/hostname
      containers:
      - name: vllm
        image: vllm/vllm-openai:v0.17.1
        args:
        - --model
        - /models/Qwen2-7B-Instruct
        - --host
        - "0.0.0.0"
        - --port
        - "8000"
        - --trust-remote-code
        - --gpu-memory-utilization
        - "0.9"
        - --max-model-len
        - "4096"
        - --enable-chunked-prefill
        resources:
          limits:
            nvidia.com/gpu: 1
            memory: "16Gi"
            cpu: "4"
          requests:
            memory: "8Gi"
            cpu: "2"
        volumeMounts:
        - name: models
          mountPath: /models
        ports:
        - containerPort: 8000
          name: http
        livenessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 120
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 60
          periodSeconds: 5
      volumes:
      - name: models
        persistentVolumeClaim:
          claimName: models-pvc
---
apiVersion: v1
kind: Service
metadata:
  name: vllm-service
  namespace: llm-serving
spec:
  type: ClusterIP
  selector:
    app: vllm
    model: qwen-7b
  ports:
  - port: 8000
    targetPort: 8000
    name: http
