Exporter（导出器）是监控系统中的一个核心数据采集组件，通常与 Prometheus 这类时序数据库配合使用。它的核心职责是将各种监控目标（如操作系统、应用程序、数据库、硬件设备）的内部运行状态 and 指标，抓取并转换为 Prometheus 能够直接识别和存储的标准化格式（通常是 HTTP 接口暴露的纯文本数据）。简单来说，Exporter 充当了一个“翻译官”的角色，架起了异构系统与统一监控平台之间的桥梁。通过部署对应的 Exporter（如 node_exporter 用于服务器硬件指标，mysqld_exporter 用于 MySQL 数据库指标），我们可以轻松实现对各类基础设施和服务的性能监控、健康状态检查与告警。

tar -xf node_exporter-1.10.2.linux-amd64.tar.gz -C /usr/local/

ln -s /usr/local/node_exporter-1.10.2.linux-amd64 /usr/local/node_exporter

# 设置文件权限
sudo chown -R prometheus:prometheus /usr/local/node_exporter-1.10.2.linux-amd64
sudo chown -R prometheus:prometheus /usr/local/node_exporter


sudo tee /etc/systemd/system/node_exporter.service > /dev/null <<EOF
[Unit]
Description=Node Exporter
Documentation=https://prometheus.io/docs/guides/node-exporter/
Wants=network-online.target
After=network-online.target

[Service]
User=prometheus
Group=prometheus
Type=simple
Restart=on-failure
ExecStart=/usr/local/node_exporter/node_exporter \
    --web.listen-address=:9100 \
    --path.rootfs=/

[Install]
WantedBy=multi-user.target
EOF


# 创建配置目录
sudo mkdir -p /etc/node_exporter/textfile_collector
sudo chown -R prometheus:prometheus /etc/node_exporter

# 设置目录权限
sudo chmod 755 /etc/node_exporter
sudo chmod 755 /etc/node_exporter/textfile_collector

sudo systemctl daemon-reload
sudo systemctl start node_exporter
sudo systemctl status node_exporter
sudo systemctl enable node_exporter

# 监控网站 HTTP/HTTPS
- job_name: 'website_http'
  metrics_path: /probe
  params:
    module: [http_2xx]
  static_configs:
    - targets:
      - 'https://www.baidu.com'
      - 'https://www.google.com'
  relabel_configs:
    - source_labels: [__address__]
      target_label: __param_target
    - source_labels: [__param_target]
      target_label: instance
    - target_label: __address__
      replacement: 127.0.0.1:9115

# 监控 SSH 服务
- job_name: 'ssh_services'
  metrics_path: /probe
  params:
    module: [ssh_banner]
  static_configs:
    - targets:
      - '10.1.0.60:22'
      - '10.1.0.80:22'
  relabel_configs:
    - source_labels: [__address__]
      target_label: __param_target
    - source_labels: [__param_target]
      target_label: instance
    - target_label: __address__
      replacement: 127.0.0.1:9115
      
# 监控 TCP 端口连通性
- job_name: 'tcp_ports'
  metrics_path: /probe
  params:
    module: [tcp_connect]  # 使用TCP连接探测模块
  static_configs:
    - targets:
      - '10.1.0.60:22'
      - '10.1.0.80:22'
  relabel_configs:
    - source_labels: [__address__]
      target_label: __param_target
    - source_labels: [__param_target]
      target_label: instance
    - target_label: __address__
      replacement: 127.0.0.1:9115
      
# 监控 ICMP (Ping)
- job_name: 'icmp_ping'
  metrics_path: /probe
  params:
    module: [icmp]
  static_configs:
    - targets:
      - '10.1.0.60'
      - '10.1.0.80'
  relabel_configs:
    - source_labels: [__address__]
      target_label: __param_target
    - source_labels: [__param_target]
      target_label: instance
    - target_label: __address__
      replacement: 127.0.0.1:9115
步骤 关键标签 __address__ 新标签 __param_target 新标签 instance 说明
初始状态 https://example.com (不存在) (不存在) Prometheus 从配置文件中读取目标。
规则 1 后 https://example.com https://example.com (不存在) 将目标地址保存为参数，用于后续传递给 Blackbox。
规则 2 后 https://example.com https://example.com https://example.com 将目标地址保留为 instance 标签，便于在UI中识别。
规则 3 后 127.0.0.1:9115 https://example.com https://example.com 重写实际抓取地址，指向 Blackbox Exporter。

最终抓取的 URL：
http://127.0.0.1:9115/probe?target=https://example.com
