vLLM核心概念

PagedAttention（分页注意力）

是什么：一种高效的显存管理技术，类似于操作系统的虚拟内存分页。

传统方式的问题：

  • KV Cache 预分配固定大小
  • 显存浪费严重
  • 无法支持长序列

PagedAttention 的解决：

  • 按需分配 KV Cache
  • 类似内存分页，按块管理
  • 显存利用率可达 90%+

Continuous Batching（连续批处理）

是什么：动态批处理技术，不用等待所有请求完成就开始处理新请求。

传统方式：

1
2
3
4

请求1 ━━━━━━━━━━━━━━━━ 等待 ━━━━━━━━━━━━━━━━ 完成
请求2 ━━━━━ 等待 ━━━━━━━━━━━━━━━━━━━━━━━━━ 完成
请求3 ━━━━━━━ 等待 ━━━━━━━━━━━━━━━━━━━━━ 完成
        ↑ 所有请求必须等最慢的完成

运维价值：

  • 吞吐量提升 10-20 倍
  • 用户等待时间更短
  • GPU 利用率更高

参数详解

参数 说明 默认值

--shm-size=16g 共享内存大小，大模型需要较大值 64MB
-v /data/models:/models 挂载模型目录 -
-p 8000:8000 端口映射 -
--model 模型路径 必填
--host 监听地址 127.0.0.1
--port 服务端口 8000
--trust-remote-code 信任远程代码 False

#!/bin/bash
# vLLM API调用脚本

VLLM_URL="http://localhost:8000/v1/chat/completions"

# 发送对话请求
curl -s "$VLLM_URL" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen2-7B-Instruct",
    "messages": [
      {"role": "system", "content": "你是一个有帮助的AI助手。"},
      {"role": "user", "content": "请介绍一下Kubernetes的基本概念"}
    ],
    "max_tokens": 500,
    "temperature": 0.7
  }' | jq '.choices[0].message.content'

#!/bin/bash
# stream_chat.sh - 流式输出并实时显示

curl -s http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen2-7B-Instruct",
    "messages": [{"role": "user", "content": "请写一首关于春天的诗"}],
    "max_tokens": 200,
    "stream": true
  }' | while IFS= read -r line; do
    # 跳过空行和 [DONE] 标记
    [[ -z "$line" || "$line" == "data: [DONE]" ]] && continue
    # 提取内容部分
    content=$(echo "$line" | sed 's/^data: //' | jq -r '.choices[0].delta.content // empty' 2>/dev/null)
    [[ -n "$content" ]] && printf "%s" "$content"
  done
echo
