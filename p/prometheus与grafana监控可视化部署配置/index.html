Prometheus + Grafana 是一个完整的监控解决方案：Prometheus 负责采集和存储系统的时序指标数据，而 Grafana 则负责将这些数据可视化，通过丰富的图表和仪表盘展示出来，让用户能够直观地监控系统运行状态。

官网：https://grafana.com

大屏：https://grafana.com/grafana/dashboards/

# Grafana 代理配置
location /grafana/ {
    proxy_pass http://127.0.0.1:3000/;
    
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    
    # Grafana 特定配置
    proxy_set_header X-Grafana-Referer $scheme://$host/grafana;
    
    # 重写路径，移除 /grafana 前缀
    rewrite ^/grafana/(.*)$ /$1 break;
    
    # 超时设置
    proxy_connect_timeout 30s;
    proxy_send_timeout 30s;
    proxy_read_timeout 30s;
    
    # WebSocket 支持（Grafana Live 功能需要）
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}

# 处理 Grafana 的静态资源
location /grafana/public/ {
    proxy_pass http://127.0.0.1:3000/public/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

默认用户名和密码为 admin/admin。

Grafana 画图

Grafana 是一款开源可视化工具，可连接 Prometheus、Consul 等多种数据源，通过拖拽操作快速搭建折线图、柱状图、仪表盘等丰富图表，支持自定义指标筛选、标签关联和时间范围调整，能将监控数据转化为直观易懂的可视化面板，还可设置告警规则，助力高效监控数据洞察与问题排查。

配置步骤：

  1. 新建 Panel → 选择 Table
  2. 设置 Transform：
    • 添加 Outer join
    • 按 instance, mountpoint 合并
  3. 字段覆盖：
    • size_bytes: 单位 bytes(IEC), 显示名称 “总大小”
    • avail_bytes: 单位 bytes(IEC), 显示名称 “可用空间”
    • used_bytes: 单位 bytes(IEC), 显示名称 “已用空间”
  4. 添加计算字段 “使用率”：(used_bytes / size_bytes) * 100
