OpenVPN 是一款基于开源技术的虚拟专用网络（VPN）解决方案，通过 SSL/TLS 加密协议在公共网络（如互联网）中建立安全的“加密隧道”，实现远程设备与企业内网的安全互联。在企业场景中，它是解决“远程办公访问内网资源”“分支机构互联”“跨地域数据安全传输”的核心工具之一，兼具安全性、灵活性与低成本优势。

OpenVpn客户端连接工具：OpenVPN-2.6.15-I001-amd64.zip

OpenVPN 简介

VPN 基础概念

  • 专用网：需向运营商租用专线，仅传输自身数据，安全稳定但成本高，适用于对安全性要求极高且预算充足的场景。
  • VPN（Virtual Private Network，虚拟私有网络）：能在不安全的公共网络（如互联网）上建立安全的数据传输通道，通过加密技术保障数据传输的机密性、完整性和可用性，成本远低于专用网，广泛应用于企业分公司互联、员工远程办公等场景。

OpenVPN 特点与优势

OpenVPN 是一款开源的 VPN 实现软件，具备以下核心特性：

  • 安全性强：支持 SSL/TLS 协议进行身份认证和数据加密，可搭配 AES-256-CBC 等高强度加密算法，同时支持 Diffie-Hellman（DH）密钥交换、tls-auth 防 DoS 攻击等安全机制。
  • 灵活性高：支持 TCP/UDP 两种传输协议，可通过代理建立隧道，兼容 NAT 环境，支持动态 IP 和 DHCP，能适应复杂网络场景。
  • 可扩展性好：可支持数百至数千用户同时连接，适用于中小型到大型企业的规模需求。
  • 跨平台兼容：可运行于 Windows、Linux（如 CentOS、Ubuntu）、macOS、Android、iOS 等主流操作系统。
  • 开源免费：基于 GPL 协议开源，企业无需支付软件授权费用，可根据需求自定义修改代码。

其官网地址为 https://openvpn.net， GitHub 仓库地址为 https://github.com/OpenVPN/openvpn，便于获取官方文档和最新版本。

OpenVPN 搭建详细步骤

部署环境准备（基于两台主机规划）

本次搭建基于两台主机，具体网络规划如下：

主机角色 公网 IP 内网 IP 用途说明
OpenVPN 服务器 120.27.157.182 172.16.20.156 提供 VPN 服务，对接公网与内网
内网服务器 -（无公网 IP） 172.16.20.155 企业内网服务节点（如 Web、数据库）

网络基础配置

阿里云服务器环境配置（OpenVPN 服务器）

创建专有网络与交换机

  • 登录阿里云控制台，创建专有网络，指定所在城市和可用区，网段名称设为 “vpn-net”，地址段选择 “172.16.0.0/12”。
  • 在该专有网络下创建交换机，名称设为 “vpn-net-sw”，可用区与服务器一致，IPv4 地址段设为 “172.16.20.0/24”（需包含 OpenVPN 服务器和内网 Web 服务器的内网 IP）。

安全组配置

为 OpenVPN 服务器所在安全组添加入方向规则，开放以下端口：

  • 协议类型：自定义 TCP，端口范围：1194/1194，授权对象：0.0.0.0/0
  • 协议类型：自定义 UDP，端口范围：1194/1194，授权对象：0.0.0.0/0
  • 协议类型：自定义 TCP，端口范围：22/22，授权对象：0.0.0.0/0
  • 协议类型：全部 ICMP（IPv4），授权对象：0.0.0.0/0

服务器初始化

  • 重置两台服务器的登录密码，确保密码复杂度符合安全要求。
  • 登录 OpenVPN 服务器，关闭防火墙（或配置防火墙规则开放 1194 端口），执行命令：
1
2

systemctl stop firewalld
systemctl disable firewalld

1

找到以下配置项并修改：

  • 将 set_var EASYRSA_CA_EXPIRE 3650 改为 set_var EASYRSA_CA_EXPIRE 36500（延长至 100 年）。
  • 将 set_var EASYRSA_CERT_EXPIRE 825 改为 set_var EASYRSA_CERT_EXPIRE 3650（延长至 10 年）。

生成 Diffie-Hellman 密钥

Diffie-Hellman 密钥交换方法是一种安全协议，让双方在完全没有对方任何预先信息的条件下通过不安全信道建立起一个密钥。

1
2

cd /etc/openvpn/easy-rsa-server/3
./easyrsa gen-dh

status /var/log/openvpn/openvpn-status.log

mute 20
tls-auth /etc/openvpn/certs/ta.key 0
crl-verify /etc/openvpn/easy-rsa-server/3/pki/crl.pem

客户端安装与配置

  1. 下载并安装 OpenVPN 客户端：访问 https://openvpn.net/community-downloads/。
  2. 导入客户端配置文件：将服务器上的五个文件复制到 Windows 的 C:\Program Files\OpenVPN\config 目录中。

  1. 连接 VPN：运行 “OpenVPN GUI”，右键点击图标选择 “Connect”。

变为绿色即为VPN连接成功。
