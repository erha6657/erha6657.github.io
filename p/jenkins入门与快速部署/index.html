DevOps 是"Development"（开发）和"Operations"（运维）的组合词，是一种文化理念、实践和工具的集合，旨在缩短软件开发生命周期，提高交付速度和质量。

DevOps 的核心原则

  • Culture（文化）：打破部门墙，共享责任
  • Automation（自动化）：流程自动化，减少人为错误
  • Lean（精益）：小批量工作，快速反馈
  • Measurement（度量）：数据驱动决策
  • Sharing（共享）：知识共享，透明沟通

DevOps 生命周期（CI/CD 流水线） 

1

计划(Plan) → 编码(Code) → 构建(Build) → 测试(Test) → 发布(Release) → 部署(Deploy) → 运营(Operate) → 监控(Monitor)

持续集成的流程

什么是 Jenkins？

Jenkins 是一款开源的自动化部署服务器，主要用于实现软件开发中的持续集成（CI） 和持续部署（CD） 流程。简单来说，它能自动完成代码编译、测试、打包、部署等重复性工作，让开发团队更专注于代码编写，而非繁琐的流程操作。

Jenkins 的核心价值在于：

  • 自动化：替代人工执行构建、测试、部署等步骤
  • 及时性：代码提交后立即触发自动化流程，快速发现问题
  • 可扩展性：通过插件生态支持几乎所有主流开发工具和平台

Jenkins 的核心概念

流水线（Pipeline）

流水线是 Jenkins 的核心功能，用于定义从代码到部署的完整自动化流程。可以理解为 “把开发流程的每一步（如拉取代码→编译→测试→部署）写成一个可执行的脚本”，支持复杂的分支逻辑（如条件判断、循环）。

流水线通常以代码形式（Jenkinsfile）存储在项目仓库中，实现 “流水线即代码”（Pipeline as Code），便于版本控制和团队协作。

任务（Job）

任务是 Jenkins 中最基本的执行单元，代表一个具体的自动化任务（如 “构建 Java 项目”、“运行 Python 测试”）。常见任务类型包括：

  • 自由风格项目（Freestyle project）：适合简单流程
  • 流水线项目（Pipeline project）：适合复杂流程
  • 多配置项目（Multi-configuration project）：适合多环境 / 多版本并行测试

插件（Plugins）

Jenkins 的强大之处在于其丰富的插件生态，通过插件可以扩展支持各种语言、工具和服务。例如：

  • 代码管理：Git插件
  • 构建工具：Maven、npm 插件
  • 测试工具：JUnit、pytest 插件
  • 部署工具：Docker、Kubernetes、SSH 插件
  • 通知工具：Email、Slack 插件

节点（Nodes）

Jenkins 可以通过 “节点” 扩展计算能力：

  • 主节点（Master）：运行 Jenkins 核心服务的服务器
  • 代理节点（Agent）：分担主节点的任务执行压力，可分布在不同机器上（支持 Windows、Linux、macOS），适合多环境测试（如同时在 Python 3.8 和 3.9 上运行测试）

利用OpenResty代理Jenkins服务

使用OpenResty代理Jenkins服务主要出于安全性、性能和功能扩展的考虑。在安全层面，OpenResty作为反向代理可以隐藏Jenkins直接暴露在公网，提供SSL终端、WAF防护和IP白名单等安全加固；在性能方面，它能缓存静态资源、实现负载均衡和连接复用，显著降低Jenkins服务器的直接压力；同时，借助Lua脚本引擎，OpenResty还能添加自定义认证、限流和监控等增强功能，实现统一的访问入口和管理界面。这种架构不仅提升了Jenkins的稳定性和安全性，还为整个持续集成平台提供了企业级的可靠保障。

# 指定一个无法登录的系统用户作为启动用户
user jenkins;
# 配置 worker 进程数
worker_processes auto;

# 事件配置块
events {
	# 每一个 worker 进程能够同时处理的最大进程数
	worker_connections  1024;
	# 指定 I/O 模型
	use epoll;
	# 防止惊群效应
	accept_mutex on;
	# 批量分配链接数
	multi_accept on;
}

# HTTP 配置块
http {
	# 指定字符编码
	charset utf-8;
	# 隐藏OpenResty的版本号
	server_tokens off;
    # 定义缓存路径和区域（必须添加这部分）
    proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=static_cache:10m max_size=1g inactive=60m use_temp_path=off;
	# 设置日志格式
	# escape=json 是 NGINX log_format 指令的一个参数，它告诉 NGINX 在生成 JSON 日志时自动转义特殊字符，确保输出的 JSON 格式是有效的、可解析的。
	log_format json_combined escape=json '{"timestamp":"$time_iso8601","remote_addr":"$remote_addr","remote_user":"$remote_user","request":"$request","status":"$status","body_bytes_sent":"$body_bytes_sent","request_time":"$request_time","http_referer":"$http_referer","http_user_agent":"$http_user_agent","http_x_forwarded_for":"$http_x_forwarded_for","server_name":"$server_name","server_protocol":"$server_protocol","upstream_addr":"$upstream_addr","upstream_status":"$upstream_status","upstream_response_time":"$upstream_response_time","upstream_connect_time":"$upstream_connect_time","upstream_header_time":"$upstream_header_time","request_length":"$request_length","request_method":"$request_method","uri":"$uri","query_string":"$query_string","http_host":"$http_host","scheme":"$scheme","gzip_ratio":"$gzip_ratio","connection":"$connection","connection_requests":"$connection_requests","pipe":"$pipe"}';
	# 设置日志的路径
	access_log /var/log/openresty/access.log json_combined;
	# 错误日志
	error_log /var/log/openresty/error.log warn;
	# 启用 gzip 压缩
	gzip on;
	# 压缩级别：1-9，推荐 4-6（平衡性能与压缩率）
	gzip_comp_level 6;
	# 最小压缩文件大小：小于 1k 的文件不压缩（避免压缩开销大于收益）
	gzip_min_length 1k;
	# 压缩缓冲区：4 个 16k 大小的缓冲区
	gzip_buffers 4 16k;
	# 压缩协议版本：支持 HTTP/1.0 及以上
	gzip_http_version 1.0;
	# 对代理请求启用压缩（如反向代理场景）
	gzip_proxied any;
	# 在响应头添加 Vary: Accept-Encoding，帮助代理服务器正确缓存
	gzip_vary on;
	# 指定需要压缩的 MIME 类型（按需添加）
	gzip_types text/css text/xml text/javascript;
	# 载入 OpenResty 能够识别的文件的类型
	include mime.types;
	# OpenResty 无法识别文件类型时，默认的文件类型
	default_type  application/octet-stream;
	# 提升系统文件句柄效率
	sendfile        on;
	# 65秒无请求则关闭连接
	keepalive_timeout 65s;
	# 最多处理1000个请求后关闭连接
	keepalive_requests 1000;
	# 合并数据包发送（适合静态资源）
	tcp_nopush on;
	# 减少交互延迟（适合动态内容）
	tcp_nodelay on;
	# 载入外部的HTTP配置块内部的配置
	include /usr/local/openresty/nginx/conf/conf.d/*.conf;
}

# 预定义WebSocket连接升级变量（Nginx 1.13+支持）
map $http_upgrade $connection_upgrade {
		default upgrade;
		'' close;
}

server {
    listen 80;
    server_name _;
    
    # 安全头部（保留原有）
    add_header X-Frame-Options DENY;
    add_header X-Content-Type-Options nosniff;
    add_header X-XSS-Protection "1; mode=block";
    add_header Referrer-Policy "strict-origin-when-cross-origin";
    
    # 隐藏 Jenkins 版本信息（保留原有）
    proxy_hide_header X-Jenkins;
    proxy_hide_header X-Jenkins-Session;
    proxy_hide_header X-Instance-Identity;

    # 若Jenkins上下文路径为根路径（无前缀），直接重写为代理服务器地址
    proxy_redirect http://localhost:8080/ /;
    # 兼容Jenkins可能的非标准端口跳转（兜底）
    proxy_redirect http://localhost:8080 $scheme://$host;
    
    location / {
        proxy_pass http://localhost:8080;
        
        # 关键代理头部（补充官方要求的核心字段）
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
			  # 必设：告知Jenkins原始协议（HTTP/HTTPS）
        proxy_set_header X-Forwarded-Proto $scheme;
				# 必设：告知Jenkins原始主机名
        proxy_set_header X-Forwarded-Host $host;
				# 必设：告知Jenkins原始端口
        proxy_set_header X-Forwarded-Port $server_port;
        proxy_set_header X-Forwarded-Server $host;
        
        # Jenkins CSRF 支持（保留原有）
        proxy_set_header X-CSRF-Token $http_x_csrf_token;
        
        # 缓冲区设置（保留原有，优化响应处理）
        proxy_buffering on;
        proxy_buffer_size 128k;
        proxy_buffers 4 256k;
        proxy_busy_buffers_size 256k;
        
        # 超时设置（延长，适配Jenkins慢操作）
        proxy_connect_timeout 60s;
				# 适配大文件上传/构建日志输出
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
        
        # WebSocket 支持（强化Jenkins兼容性，如实时日志、Agent连接）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
		    # 动态适配Upgrade请求
        proxy_set_header Connection $connection_upgrade;
    }
    
    # 静态资源缓存（保留原有，优化加载速度）
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        proxy_pass http://localhost:8080;
        proxy_cache static_cache;
				# 延长静态资源缓存时间
        proxy_cache_valid 200 302 24h;
        proxy_cache_valid 404 10m;
        expires 7d;
        add_header X-Cache-Status $upstream_cache_status;
				# 静态资源也需传递Host头，避免路径错误
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

权限解释

权限类别 权限名称 英文名称 详细说明
凭据 创建 Create 创建新的凭据（密码、SSH密钥、API令牌等）
删除 Delete 删除现有凭据
管理域 ManageDomains 管理凭据域（组织和管理凭据的命名空间）
更新 Update 修改现有凭据信息
查看 View 查看凭据信息（但看不到敏感内容如密码）
任务 构建 Build 触发任务执行构建过程
取消 Cancel 取消正在运行的构建任务
配置 Configure 修改任务的配置设置
创建 Create 创建新的任务
删除 Delete 永久删除任务及其构建历史
发现 Discover 在任务列表中看到任务（无Read权限时不能查看详情）
移动 Move 移动或重命名任务
读取 Read 查看任务详情、构建历史、控制台输出等
工作空间 Workspace 访问任务的工作空间文件和构建产物
运行 删除 Delete 删除构建记录和历史数据
重放 Replay 使用相同参数重新运行构建
更新 Update 更新构建信息（如描述、参数等）
视图 配置 Configure 配置视图（添加/移除任务，修改视图设置）
创建 Create 创建新的视图
删除 Delete 删除视图
读取 Read 查看视图内容和包含的任务
