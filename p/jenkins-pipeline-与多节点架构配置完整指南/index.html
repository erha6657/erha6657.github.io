Jenkins Pipeline 是一种基于代码的持续集成/持续交付（CI/CD）流程定义框架，通过 Groovy 语法将整个软件交付过程建模为可版本控制的 Jenkinsfile 脚本，支持从代码编译、测试、静态分析到容器构建、部署的全链路自动化，其声明式语法提供结构化模板简化编写，而脚本式语法允许高级流程控制，具备可视化阶段日志、并行执行、错误恢复和人工审核等企业级特性，实现复杂交付流程的可重复、可审计和可维护管理。

Jenkins pipeline 需要 pipeline、docker pipeline 和 pipeline stage view 插件。

什么是 Jenkins Pipeline？

Jenkins Pipeline 是一套插件，用于支持在 Jenkins 中实现持续交付流水线即代码。它允许你以代码的形式定义整个构建、测试和部署过程，这些代码可以被提交到版本控制系统中进行管理。

Pipeline 有两种语法形式：

  • 声明式（Declarative）：一种更结构化、更简洁的语法，适合大多数常见场景
  • 脚本式（Scripted）：基于 Groovy 语言的更灵活的语法，适合复杂场景

本指南将以声明式语法为主，循序渐进地介绍 Pipeline 的核心概念和用法。

基础入门：第一个 Pipeline

创建一个文件 Jenkinsfile（通常存放在项目根目录）：

pipeline {
    agent any
    stages {
        stage('Hello') {
            steps {
                echo 'Hello, Jenkins Pipeline!'
            }
        }
    }
}

解释：

  • pipeline：整个流水线的根块
  • agent any：指定流水线可以在任何可用的 Jenkins 代理（节点）上运行
  • stages：包含一个或多个阶段的集合
  • stage：流水线中的一个阶段，通常代表构建过程中的一个环节
  • steps：在阶段中执行的具体操作

Jenkins 多节点

Jenkins 多节点架构允许将构建工作负载分布到多个机器上，提供以下优势：

  • 横向扩展：应对高并发构建需求
  • 环境隔离：不同项目使用不同的构建环境
  • 资源优化：合理分配计算资源
  • 专用环境：特定平台（Windows、macOS、Linux）的构建需求

pipeline {
    agent any
    stages {
        stage('Steps Demo') {
            steps {
                // 执行 shell 命令
                sh 'echo "This is a shell command"'
                sh '''
                    echo "Multi-line shell script"
                    ls -la

					ip a

					pwd

					touch README.md
                '''
				
                // 输出信息
                echo 'This is a simple message'
                
				// 1. 写入文件
                writeFile file: 'example.txt', text: '这是一些文本内容'
                
                // 2. 读取文件
                script {
                    def fileContent = readFile('example.txt')
                    echo "文件内容: ${fileContent}"
                }
                
                // 3. 检查文件是否存在
                script {
                    if (fileExists('example.txt')) {
                        echo "文件存在"
                    } else {
                        echo "文件不存在"
                    }
                }
                
                // 4. 创建目录并写入文件
                dir('subdirectory') {
                    writeFile file: 'nested.txt', text: '子目录中的文件'
                }

            }
        }
    }
}

注意：有些步骤需要包裹在 script 块中，因为它们返回值需要被处理。

    environment {
        // 定义全局环境变量

                echo "Application name: ${APP_NAME}"
                echo "Stage variable: ${STAGE_VAR}"
                // 注意：不会显示实际密码，会被 Jenkins 自动屏蔽
                echo "DB password: ${DB_PASSWORD}"
                
                // 在 shell 中使用环境变量

pipeline {
    agent any
    parameters {
        booleanParam(name: 'DEPLOY', defaultValue: false, description: 'Deploy after build?')
        choice(name: 'ENVIRONMENT', choices: ['dev', 'test', 'prod'], description: 'Deployment environment')
    }
    stages {
        stage('Build') {
            steps {
                echo 'Building...'
            }
        }
        stage('Test') {
            steps {
                echo 'Testing...'
            }
        }
        stage('Deploy to Dev') {
            when {
                allOf {
                    expression { params.DEPLOY == true }
                    environment name: 'ENVIRONMENT', value: 'dev'
                }
            }
            steps {
                echo 'Deploying to development environment...'
            }
        }
        stage('Deploy to Prod') {
            when {
                allOf {
                    expression { params.DEPLOY == true }
                    environment name: 'ENVIRONMENT', value: 'prod'
                }
            }
            steps {
                echo 'Deploying to production environment...'
            }
        }
    }
}

when 指令支持多种条件判断：

  • branch：当分支匹配时
  • environment：当环境变量匹配时
  • expression：当 Groovy 表达式为真时
  • not：对其他条件取反
  • allOf：所有条件都满足时
  • anyOf：任何一个条件满足时

pipeline {
    agent any
    stages {
        stage('Test') {
            steps {
                echo 'Running tests...'
                // sh 'mvn test'
            }
        }
    }
    post {
        always {
            echo 'This will always run'
        }
        success {
            echo 'This will run only if successful'
        }
        failure {
            echo 'This will run only if failed'
        }
        unstable {
            echo 'This will run only if the run was marked as unstable'
        }
        changed {
            echo 'This will run only if the status changed from the previous run'
        }
    }
}
后置条件 执行时机 使用场景
always 总是执行，无论构建结果如何 清理工作、发送通知、记录日志
success 仅当构建成功完成时执行 部署到生产环境、发送成功通知、生成报告
failure 仅当构建失败时执行 发送失败通知、记录错误信息、回退操作
unstable 仅当构建被标记为不稳定时执行 测试失败但构建未完全失败时的处理
changed 仅当构建状态与上一次不同时执行 状态变化通知、差异分析

根据 git log 生成版本号

在 CI/CD 中，版本号通常需要关联代码提交记录（如包含提交次数、哈希值），方便追溯版本对应的代码。通过 git log 命令可提取关键信息，再组合成版本号。

常用 git log 命令（用于提取版本信息）

命令 作用 示例输出
git rev-parse --short HEAD 获取当前提交的短哈希（8 位） a1b2c3d4
`git log –oneline wc -l` 统计总提交次数（作为修订号）
git describe --abbrev=0 --tags 获取最近的标签（如 v1.2.3） v1.2.3
git branch --show-current 获取当前分支名 dev

生成版本号的常见格式

结合上述信息，常见版本号格式：

  • 主版本.次版本.提交次数-短哈希（如 1.0.123-a1b2c3d4）
  • 标签-提交次数-分支-短哈希（如 v1.2.3-45-dev-f6g7h8i9）

pipeline {
  agent any
  parameters {
    string(
      name: 'MAIN_VERSION',
      defaultValue: '2.1',
      description: '主版本号（如2.1）'
    )
    choice(
      name: 'BUILD_TYPE',
      choices: ['release', 'snapshot'],
      description: '构建类型（正式版/快照版）'
    )
    booleanParam(
      name: 'INCLUDE_BRANCH',
      defaultValue: true,
      description: '版本号中是否包含分支名'
    )
  }
  stages {
    stage('Generate Version') {
      steps {
        script {
          // 1. 基础信息
          def gitShortHash = sh(script: 'git rev-parse --short HEAD', returnStdout: true).trim()
          def commitCount = sh(script: 'git log --oneline | wc -l', returnStdout: true).trim()
          def branchName = sh(script: 'git branch --show-current', returnStdout: true).trim().replace('/', '-') // 替换特殊字符

          // 2. 拼接版本号
          def versionParts = ["${params.MAIN_VERSION}.${commitCount}"]
          if (params.INCLUDE_BRANCH) {
            versionParts << branchName
          }
          versionParts << gitShortHash
          if (params.BUILD_TYPE == 'snapshot') {
            versionParts << 'SNAPSHOT'
          }

          env.APP_VERSION = versionParts.join('-')
          echo "最终版本号: ${env.APP_VERSION}" 
          // 示例：2.1.156-dev-a1b2c3d4-SNAPSHOT
        }
      }
    }
    stage('Build') {
      steps {
        sh "echo 构建版本: ${env.APP_VERSION}"
        // 实际构建命令（如Docker打包）
        sh "docker build -t my-app:${env.APP_VERSION} ."
      }
    }
  }
}

pipeline {
    agent any
    environment {
        PATH="/usr/local/go/bin:/usr/local/maven/bin:/usr/local/node-v24.11.0/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/root/bin"
    }
    parameters {
        listGitBranches branchFilter: 'refs/heads/(.*)', credentialsId: '5aab4515-5676-49c9-966a-7a8f0045b7a2', defaultValue: 'master', description: 'git分支参数', listSize: '5', name: 'BRANCHE', quickFilterEnabled: false, remoteURL: 'http://10.1.0.61/hellowolrd/java.git', selectedValue: 'NONE', sortMode: 'NONE', tagFilter: '*', type: 'PT_BRANCH'
    }
    stages {
        stage("环境预检查"){
            steps {
                sh """
                    java -version

                    mvn --version
                """
            }
        }

        stage("拉取Git仓库代码") {
            steps {
                git branch: "$BRANCHE", credentialsId: '5aab4515-5676-49c9-966a-7a8f0045b7a2', url: 'http://10.1.0.61/hellowolrd/java.git'
            }
        }

        stage("编译代码"){
            steps {
                sh """
                    mvn clean package
                """
            }
        }

        stage("代码质量检查"){
            environment {
                SONAR_SCANNER_HOME = tool 'SonarQubeScanner'
            }
            steps {
                script {
                    echo "开始写入SonarQube配置文件"
                    writeFile encoding: 'utf-8', file: 'sonar-project.properties', text: """sonar.projectName=${JOB_NAME}
sonar.projectKey=${JOB_NAME}
sonar.projectVersion=${BUILD_NUMBER}
sonar.sources=./
sonar.java.binaries=target/classes
sonar.exclusions=src/test/**/*,src/main/resources/**/*.xml,target/**/*, **/node_modules/**/*
sonar.language=java
sonar.sourceEncoding=UTF-8
sonar.issuesReport.publish=true
                    """

                    echo "写入SonarQube配置文件完毕"

                    withSonarQubeEnv(credentialsId: '133c2ed5-4330-4502-a81f-ed4a9015b182') {
                        
                        sh """
                            echo "SonarQube Scanner 路径: ${SONAR_SCANNER_HOME}"
                            echo "开始代码质量扫描..."
                            ${SONAR_SCANNER_HOME}/bin/sonar-scanner
                        """

                    }
                }
            }
        }

        stage("等待质量门结果"){ // 单独处理质量门等待
            steps {
                script {
                    timeout(2) {
                        def sonarQubeStatus = waitForQualityGate(abortPipeline: true, credentialsId: '133c2ed5-4330-4502-a81f-ed4a9015b182')
                        echo "质量门状态: ${sonarQubeStatus.status}"
                        echo "质量门详情: ${sonarQubeStatus}"
                        if (sonarQubeStatus.status != 'OK') {
                            error "❌ 代码质量检查未通过！当前状态: ${sonarQubeStatus.status}"
                        } else {
                            echo "✅ 代码质量检查通过！"
                        }
                    }
                }
            }
        }
        stage("发布代码并使其生效") {
            steps {
                sshPublisher(publishers: [sshPublisherDesc(configName: 'web', transfers: [sshTransfer(cleanRemote: false, excludes: '', execCommand: 'ls', execTimeout: 120000, flatten: false, makeEmptyDirs: false, noDefaultExcludes: false, patternSeparator: '[, ]+', remoteDirectory: 'java', remoteDirectorySDF: false, removePrefix: '', sourceFiles: 'target/*.jar')], usePromotionTimestamp: false, useWorkspaceInPromotion: false, verbose: false)])
            }
        }
    }
    post {
        always {
            echo "Hello World"
        }

        success {
            echo "Hello World"
        }

        failure {
            echo "Hello World"
        }
    }
}
